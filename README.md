# Jyoti Models Website

Jyoti Models is a professional multi-page science educational website developed for a firm to provide subject-wise educational content in an organized and interactive manner. The website is designed with a clean user interface and smooth navigation to enhance user experience.

This platform includes multiple pages dedicated to various scientific subjects such as Botany, Zoology, Physics, Anatomy, and Forensic Science, along with essential pages like Home, About Us, Contact, and Workplace.

## Features

- Responsive and user-friendly design  
- Multi-page website structure  
- Subject-specific educational pages  
- Smooth navigation between pages  
- Professional layout and design  
- Contact and workplace information pages  

## Tech Stack

- HTML5  
- CSS3  
- JavaScript  

## Purpose of the Project

The purpose of this project is to create an informative and professional online platform for a firm where users can easily access educational science-related content.
